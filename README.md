# Binance 自动化交易系统 v2.0

## 🚀 快速启动

### 三种运行模式

| 文件 | 模式 | 用途 | 风险 |
|------|------|------|------|
| **启动实盘交易.bat** | MAINNET实盘 | 真实交易 | ⚠️ 高（真实资金） |
| **启动模拟交易.bat** | 模拟交易 | 测试策略 | ✅ 无 |
| **启动调试模式.bat** | 调试模式 | 开发调试 | ✅ 无 |

## 📋 推荐流程

1. **第一次使用**：双击 `启动模拟交易.bat` 进行测试
2. **测试通过后**：双击 `启动实盘交易.bat` 开始实盘

## 🎯 系统特性

- ✅ 多时间框架分析（3m/5m/15m）
- ✅ 高级风险管理（止损/止盈/追踪）
- ✅ 动态仓位管理
- ✅ 市场过滤和异常检测
- ✅ 冷却和轮动机制
- ✅ Binance期货完整集成

## ⚙️ 配置文件

| 文件 | 说明 |
|------|------|
| `config_v2.py` | 完整策略配置 |
| `trading_engine_v2.py` | 主交易引擎 |
| `risk_manager_v2.py` | 风险管理模块 |
| `signal_generator.py` | 信号生成模块 |
| `position_monitor_v2.py` | 持仓监控模块 |

## 📊 关键指标

- **最小信号得分**：7分（满分12分）
- **基础仓位**：12 USDT
- **杠杆倍数**：1x
- **最小名义价值**：5.5 USDT

## 🔐 安全说明

- 实盘交易需要二次确认
- 支持紧急平仓（紧急平仓.bat）
- 所有持仓自动管理止损和止盈
